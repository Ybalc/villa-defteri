# Villa Defteri

Villa rezervasyon takvimi, misafir/ödeme takibi ve gelir-gider raporu. Veriler Supabase'te.

- `www/index.html` – uygulamanın tamamı (web ve Android aynı dosyayı kullanır)
- `supabase/kurulum.sql` – veritabanı kurulumu (Supabase → SQL Editor'de bir kez çalıştırılır)
- `.github/workflows/build.yml` – her güncellemede web sürümünü GitHub Pages'e yayınlar ve APK'yı derleyip **Releases → son-surum** altına koyar
